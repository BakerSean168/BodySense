# Project showcase (static snapshot)

This directory is a self-contained, point-in-time product showcase page.
It is published as-is by .github/workflows/pages.yml (GitHub Pages) and is
**not** kept in sync with the running product: the screenshots and flows
shown here are a snapshot from 2026-10-13 (last content update) and may
lag behind the current UI.

Do not use this page as API or integration documentation. The contract
authority is packages/contracts/openapi/bodysense.v1.openapi.yaml; the
Postman collection under postman/ is a generated projection of it
(see postman/README.md). Product documentation lives in docs/.

Updating this snapshot is a deliberate, manual step: replace the page and
assets in one commit and note the new snapshot date here.
