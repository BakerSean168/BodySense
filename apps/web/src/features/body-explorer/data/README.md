# Body Explorer semantic data

This directory contains BodySense-owned semantic data plus a reproducible normalized inventory of the pinned Vanatome atlas.

## Atlas registry boundary

`vanatome-1.4.0-registry.generated.json` is metadata-only. It intentionally contains the full 807-entry structure registry needed to validate IDs and mappings, but it does not copy GLB binaries or unrelated atlas assets into Git.

The file is generated by:

```bash
python3 apps/web/src/features/body-explorer/scripts/generate-vanatome-registry.py
```

The generator defaults to the official Vanatome repository at exact upstream commit `8185b3fa46a1dbefdd907390918c57954fd9b816`, using its `demo-1.4.0` catalog and full-body metadata. The official immutable release URL is recorded as provenance in the generated file. Source SHA-256 hashes are also recorded so generation drift is visible.

The normalized registry preserves the atlas identity, parent hierarchy, system/layer, focus position, direct geometry mapping evidence, and conservative laterality evidence. Laterality is emitted only when the upstream ID/name contains explicit left/right evidence; it is not inferred spatially from coordinates.

Current pinned inventory:

- atlas release: `1.4.0`
- structures: `807`
- structures with direct geometry: `749`
- mapped GLB nodes: `984`

## BodySense ontology

`body-regions.v1.json` is the product-owned canonical region vocabulary. It does not contain Vanatome anatomy IDs.

Deterministic aliases may resolve to durable `BodyRegionId` values. Ambiguous aliases are declared separately and must resolve as `ambiguous`, never through fuzzy matching.

## Atlas mapping

`vanatome-region-map.v1.json` binds BodyRegionOntology v1 to Vanatome atlas 1.4.0. Every mapped anatomy ID is CI-validated against the generated registry, and reverse ownership is deterministic.

Machine-verifiable registry checks are complete in this lane. `visual_review` remains `pending` until the real Viewer lane is integrated and each curated region focus/highlight boundary is inspected on the 3D model. A pending visual review is not permission to invent or string-guess anatomy IDs at runtime.
