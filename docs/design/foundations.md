# BodySense · 设计 Foundations

设计 Foundations 为人体桌面、业务窗口、工具、组件和业务状态提供一致的视觉与交互语言。对应的可编辑设计令牌、组件与布局应统一维护于 Penpot **BodySense · Product Design** 的 Foundations / Components / Product 页面。

## 视觉语言

- 以人体为主要空间背景，业务窗口具有明确的层级、聚焦与遮挡关系。
- 使用统一的颜色语义区分主要动作、当前状态、注意、待确认和安全阻断。
- 字体、间距、圆角、表面、阴影和动效通过通用令牌控制。
- 证据与健康结论的状态必须由文字/结构支持，不能只依靠颜色暗示。
- 当前内容为主，来源和真实病程可按需展开；技术修订不占据界面主要空间。

## 交互基础

- 浮动窗口可打开、聚焦、拖动、收起、恢复，并处理合适的 Esc 与返回动作。
- 工具层可以临时覆盖人体交互；完成或取消后原业务任务保持上下文。
- 触控和键盘均可完成必要功能；选区提供文本替代路径。
- 加载、空态、错误、待确认、待授权与安全阻断具备不同可理解的反馈。
- 桌面、窄屏与移动端共享业务语义，按设备调整窗口/覆盖层呈现。

## 业务状态

| 概念 | 表达约束 |
| --- | --- |
| 用户自述 | 标注来源和时间，不暗示医学确诊 |
| Observation | 可查看测量/检测来源和质量 |
| Hypothesis | 明示推测性、依据与不确定性 |
| 当前 Diagnosis | 综合视图与病情条目分层表达 |
| 计划修改建议 | 与已接受的当前计划清楚区分 |
| 安全状态 | 提供原因与合理下一步，优先于普通执行 |

视觉与行为规范以 [UI 交互规格](../product/interface.md) 和实际 Penpot 组件共同约束；领域语义参照 [产品需求](../product/requirements.md)。
