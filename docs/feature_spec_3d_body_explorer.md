# BodySense · 3D 人体交互规格

## 目标

3D 人体是 BodySense 工作空间持续存在的底层 Canvas。用户可直接探索自己的身体区域并在需要时用工具辅助表达不适、查看相关记录和参考动作。

## 基础能力

- 在桌面/移动端提供可旋转、缩放、定位的 3D 人体交互。
- 支持按标准化身体区域进行单选、多选、点选和涂抹；选区需要文本/键盘替代入口。
- 根据任务开启肌肉、骨骼、神经等可用的解剖层与参考姿态/动作。
- Chat、Person、Diagnosis 和 Trainer 在浮动窗口呈现；窗口的打开、移动和关闭不销毁底层人体及其上下文。
- Agent 请求用户指明位置时，可在人体上临时进入选择工具，完成后把精确的部位信息回传当前会话。
- BodyState 可在人体空间关联部位记录，但必须区分用户事实、观察、推测及安全提示。

## 证据边界

选择一个区域不等于报告疼痛；显示动作示范不等于已经测量用户的姿态、受力或诊断结果。人体模型是交互参考，不是个体化医学扫描或经过验证的力学生物仿真。

## 质量与安全

模型加载、WebGL 不可用、空区域、触控操作、焦点恢复和异步取消都需要可理解的状态与退化路径。人体工具不能绕过 BodyState 的来源/确认规则或 Diagnosis 的正式分析与安全门禁。
