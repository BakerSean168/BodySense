# DigitalOcean deployment archive

> Status: **Retired 2026-08-22**

The DigitalOcean environment was a temporary cloud-native practice environment and is no longer part of BodySense CI/CD.

Production is Alibaba Cloud only:

`GitHub CI -> release-please -> immutable ACR images -> prod-latest promotion -> Alibaba Cloud production deploy watcher`.

The archived workflow, Compose file and environment template are kept only as historical/reference material. They must not be re-enabled without an explicit new deployment decision.
