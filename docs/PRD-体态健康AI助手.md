# BodySense · 产品需求文档

**产品业务规格 · 2026-10-11**

## 产品定位

BodySense 是一个 AI Agent 驱动的个人身体状态应用。用户通过自然语言、人体交互和各类证据输入持续记录身体状况，按需形成一份综合诊断，并管理独立的训练计划。用户看到当前内容，不需要操作内部修订记录。

## 核心业务

| 对象 | 业务规则 |
| --- | --- |
| BodyState | 一个用户一份，明确的本人身体描述自动保存；时间变化与错误更正分开；有歧义时才追问 |
| Diagnosis | 一个用户一份当前综合诊断；包含独立、可定向更新的病情条目；单次修改形成一个整体修订 |
| TrainingPlan | 一个用户可有多份独立计划；用户主动请求可定向修改，Agent 主动建议必须经用户同意 |
| Agent | 通过 Chat 和工具获取事实、证据、解释、授权；后端验证与持久化所有业务变更 |
| UI | 持续存在的 3D 人体桌面，上层按需打开 Chat、Person、Diagnosis、TrainingPlan 等浮动窗口 |

正式 Diagnosis 由用户明确请求或授权触发。模型给出的初步解释不等同于正式分析结果。已保存的训练内容不因新的身体信息或诊断变化自动更新；安全规则可独立阻断不合适的训练执行。

## 产品体验

用户可以直接提问、描述不适、浏览人体、查看自己的身体记录、请求综合分析或进入训练。按需澄清不明确的信息；清晰的本人身体自述不需要逐条手动确认。诊断按病情组织并保持证据与不确定性。训练计划的修改始终有清楚的操作目标与授权。

用户可查看真实身体状况的时间变化，但默认不显示业务修订号、历史技术版本和系统内部状态机。
